本目录包含三个完整的 Python 实战项目，涵盖 Web 开发、游戏开发和命令行应用。

## 项目列表

| 项目 | 说明 | 技术栈 |
| --- | --- | --- |
| [flask-qa-community](./flask-qa-community/) | Flask 问答社区前端 | Flask、Bootstrap、jQuery |
| [pygame-valley-farm-sim](./pygame-valley-farm-sim/) | Pygame 农场模拟游戏 | Pygame、pytmx |
| [vega-news-terminal](./vega-news-terminal/) | 命令行新闻管理系统 | colorama、MySQL |

## 说明

每个项目均为独立可运行的完整项目，进入对应目录查看详细说明。
