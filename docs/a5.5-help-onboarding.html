帮助与快捷键

入口：侧栏「帮助」（hover 提示「帮助与快捷键（⌘/）」）或 ⌘/Ctrl /；内容 = 键位 + 常用操作 + 安全边界 + 环境信息

帮助与快捷键 Esc

快捷键修饰键随平台：⌘Ctrl

⌘Ctrl K 全局搜索：打开命令面板，可搜名称 / 标签 / 代码片段 ↑↓ 在列表或面板中上下选择 ↵ 打开选中示例的详情 ⌘Ctrl ↵ 运行示例（详情页与运行器内同键） ⌘Ctrl S 保存改动（未改动时不可用） ⌘Ctrl . 停止正在运行的示例 ⌘Ctrl / 打开 / 关闭本页

常用操作

找示例
画廊按主题分区；工具箱按工具体量分组；急用时 ⌘Ctrl K 直接搜。
运行与看结果
详情页右侧「终端输出」实时显示；示例生成的图片自动收进「资源」标签，可预览与下载。
编辑与保存
左侧 Monaco 编辑器；改动后 ⌘Ctrl S 保存，内置示例可随时恢复原始版本。
安全边界：示例在独立子进程中运行（30 秒超时、环境变量白名单），但子进程隔离不是安全沙箱——反射调用、运行时拼接的命令与第三方库内部行为不受静态扫描覆盖。高危示例运行前会二次确认。
