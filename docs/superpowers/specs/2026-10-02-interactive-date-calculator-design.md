# 日期计算器（交互式页面工具）设计规格

- 日期：2026-10-02
- 状态：设计已经用户逐节确认
- 来源：「语言基础」分区 5 个 `basics-date-diff_*.py` 静态变体的升级重构

## 1. 背景与目标

「语言基础」分区现有 5 个日期计算示例（`basics-date-diff_1..5.py`），内容同构：两个硬编码日期求间隔天数与星期，仅日期区间不同。它们占据了 5 张卡片却只传达一个知识点。

目标：把这 5 个静态变体升级为**一个**交互式页面工具——工具箱卡片 + 专属交互页。用户任选起止日期即时得到丰富结果，页面同时展示随输入实时变化的等价 Python 代码，可复制、可运行，保持 PyCase「工具 + 学习」双重身份。

## 2. 已确认的需求决策

| 决策点 | 结论 |
|---|---|
| 产品形态 | C：工具箱卡片 + 专属交互页（非普通代码详情页） |
| 功能范围 | 基础日期差 + 计算增强包（月/年差、闰日、距今正倒计时、日期加减）+ 日历可视化 + 代码联动 |
| 原 5 个变体 | 退役：从生成器与库中移除，工具页**不保留**其源码入口 |
| 计算引擎 | 方案一：纯前端 TS 即时计算；代码抽屉生成的 Python 代码可复制/可运行 |
| 页面布局 | B + C 混搭：全局日期对输入行 + 四 Tab 分区 + 各 Tab 垂直叙事 + 底部折叠代码抽屉 |
| 工作日拆分 | **不做**（用户未选） |

## 3. 信息架构与入口

- 工具箱新增特殊卡片「日期计算器」，归属新分组「交互工具」，置顶展示；带「交互」徽章，无「运行」按钮，主操作为「打开」。
- 与普通工具卡片同语法：参与搜索、可收藏、计入工具总数与分组统计；不计入可运行率（无 .py 文件，不属于运行域）。
- 数据来源：前端注册表 `interactive-tools.ts`（**不进**内置库 JSON——假条目会污染可运行率统计、sidecar 文件加载与守卫测试）。ToolboxView 合并渲染注册表与目录池。
- 路由：点击卡片 → `selectedId = 'interactive:date-calculator'`；App.vue 在 DetailPage 分支前拦截该 id，渲染 `DateCalculatorPage`。返回语义与详情页一致（清 `selectedId`，沿用未保存守卫链路——本页无脏状态，恒直接返回）。

## 4. 计算核心规格（`date-core.ts`）

无 UI 依赖的纯函数模块。约定 `a`、`b` 为任意顺序输入，内部先规范化 `d1 <= d2`（交换时置 `swapped: true`，UI 显示「已自动交换」提示条）。

### 4.1 口径定义

| 量 | 定义 |
|---|---|
| 天数 | `(d2 - d1)` 的天数（d1 ≤ d2，恒 ≥ 0；同日 = 0） |
| 周数 | 天数 / 7，保留 1 位小数 |
| 规范化月年 | 整月数 `m`：`(d2年-d1年)×12 + (d2月-d1月)`，若 `d2.日 < d1.日` 则 `m-1`；余数天 = `d1 + m 个月` 到 `d2` 的天数；展示为「X 年 Y 个月 Z 天」 |
| 闰日数 | 左闭右开区间 `[d1, d2)` 内 2 月 29 日的个数 |
| 起止星期 | 本地化星期名（中文） |
| 距今 | `d - today`（本地时区当天）；正 = 未来，负 = 已过去 |
| 加减 N 月 | 目标日 = `min(原日, 目标月最后一日)`（clamp 规则，闰日随动：2024-02-29 + 1 年 = 2025-02-28） |

### 4.2 TS ↔ Python 一致性

两侧各自实现同一口径，以**固定黄金用例集**（JSON 文件，双端共享）对拍：至少覆盖 2020-02-29 起点、同日、跨年、加月 clamp、闰日计数。pytest 与 vitest 双侧门禁，用例文件任一侧失败即红灯。

## 5. 页面结构与交互规格

### 5.1 布局（已定稿的 B + C 混搭）

```
┌──────────────────────────────────────────────────┐
│ ← 日期计算器                    工具箱 · 交互工具   │ 页头
├──────────────────────────────────────────────────┤
│ [📅 d1 周一] ⇄ [📅 d2 周三]  预设: 今天/元旦/闰年日 │ 全局输入行
├──────────────────────────────────────────────────┤
│ Tabs: 日期差 | 正倒计时 | 日期加减 | 日历          │
│ ┌ Tab 内容区（垂直叙事，随 Tab 切换）──────────┐ │
│ └──────────────────────────────────────────────┘ │
├──────────────────────────────────────────────────┤
│ ▾ Python 代码（默认折叠；复制 | 运行 | 输出区）    │ 代码抽屉
└──────────────────────────────────────────────────┘
```

- **全局输入行**：两个日期输入（`input[type=date]`，Electron/Chromium 原生控件）+ 各自星期标注 + 交换按钮 + 预设 chips（今天、今年元旦、明年今天、闰年日 2024-02-29）。预设是**单日期**快捷值，写入最近聚焦的日期框（默认 d1），不构成对原变体的源码引用。
- **Tab 状态**：会话内记忆（切走再回来保持）；日期对为页面级共享状态，四 Tab 全部响应。

### 5.2 四个 Tab

| Tab | 内容 |
|---|---|
| 日期差（默认） | 大数字天数 + 指标行（周数、规范化年月天、闰日数、起止星期、距今）+ 跨度色带条（d1→d2 渐变，标注首尾月份刻度） |
| 正倒计时 | d1、d2 各自的距今天数大字（正=还有/负=已过）+ 纪念日前瞻：从该日期起第 k×100 天与第 k 周年（clamp 加年）中未来最近的 3 个，列出日期与序号 |
| 日期加减 | 增减行列表：选目标（d1/d2）× 运算（+/−）× 数值 × 单位（天/周/月/年），即时出结果日期与星期；可增删行 |
| 日历 | 双月并排日历（起月 + 讫月）、逐月翻阅、起止日期高亮（起点蓝/终点绿）、区间内日期色带；点击日历格反向设定：第一次点 = 起点，第二次点 = 终点 |

### 5.3 代码抽屉（代码联动）

- 内容按当前 Tab 实时生成等价 Python 代码（纯标准库 `datetime` / `calendar`），随输入即时刷新；各 Tab 模板：日期差 → `(d2-d1).days` + `strftime`；正倒计时 → `date.today()` 差值；日期加减 → `timedelta` 与加月 helper；日历 → `calendar.month()` + `weekday()`。
- 展示：只读 Monaco（复用现有 `MonacoEditor.vue`）。
- 操作：**复制**（写剪贴板 + toast）；**运行**（走现有 sidecar 运行链路，stdout 显示在抽屉内输出区，含退出码与耗时；sidecar 未就绪时按钮禁用）。
- 明确不出现原 5 个变体源码的任何入口/链接（用户要求）。

## 6. 组件与数据流

```
renderer/src/
├── date-core.ts            # 纯计算（§4 口径唯一实现）
├── py-codegen.ts           # 各 Tab Python 代码模板（纯函数）
├── interactive-tools.ts    # 交互工具注册表（id/标题/描述/图标）
└── store/interactive.ts    # 日期对、Tab 激活态（会话内记忆）
renderer/components/date-calculator/
├── DateCalculatorPage.vue  # 页面骨架：页头/输入行/Tabs/抽屉
├── DateRangeInputs.vue     # 全局输入行
├── TabDiff.vue / TabCountdown.vue / TabArithmetic.vue / TabCalendar.vue
└── CodeDrawer.vue          # 抽屉：Monaco + 复制/运行/输出区
```

- 数据流单向：`store/interactive.ts` 持有 `(d1, d2, activeTab)`；Tab 组件只读 store + 调 `date-core` 派生结果；输入与点格反向设定都只写 store。
- 样式全部走 theme.css v3 tokens 与 `components/base/` 现有组件，不引入新依赖。

## 7. 变体退役

1. `scripts/gen_bulk_examples.py` 删除 date-diff 模板（含其变体参数表）。
2. 重新生成 `json_examples/bulk_basics.json`（99 → 94 例）并删除 5 个 `basics-date-diff_*.py`。
3. `tests/test_guard_data.py` 等守卫的期望计数/清单同步更新。
4. 画廊、工具箱、运行器的计数全部由目录派生，无需额外清理。

## 8. 错误处理

- 日期非法/空：原生控件约束为主；解析失败时该输入框标红（`border-danger`），结果区显示引导文案（「请补全两个日期」），不崩溃、不显示过期结果。
- 输入不完整：禁用受影响的派生区（保持骨架，不闪烁）。
- sidecar 未就绪/运行失败：「运行」按钮禁用或显示错误态，复用现有 OutputPanel 的 loading/error 语义。
- 代码生成为纯模板拼接，无失败路径。
