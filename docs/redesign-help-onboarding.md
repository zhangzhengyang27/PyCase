## 1. 范围

| 面 | 本批做什么 | 不做什么 |
|---|---|---|
| 帮助 | 一个**快捷键速查面板**：键位表 + 常用操作 + 安全边界 + 环境信息 | 不写可搜索的内嵌文档、不做上下文气泡、不新增在线文档站 |
| 首启 | **全屏首启引导页**：价值说明 + 三步用法 + 环境准备可视化（进度/耗时/失败可重试）+ 开始浏览 | 不做账号/引导流程分支；不做逐页 spotlight 引导 |

并装依赖（数分钟），现状界面上**完全不可见**（只有状态栏「连接中」），用户不知道在等什么。

## 3. 首启引导页

**触发**：本地标记（`store:set('onboarding', {...})`）缺失时，在**首帧后**展示 —— 不等 sidecar ready，
否则首次启动会先白屏数分钟。

**状态机**（steps 的顺序与依赖关系来自 sidecar 的真实启动序列）：

```
启动 Python 服务 → 安装共享依赖(.venv) → 建立示例索引 → 预检可运行性
   连接             get_venv_manager()      _index 构建     预热 run_status
```

| 状态 | 呈现 |
|---|---|
| 进行中 | 该步 spinner；顶部「正在准备运行环境 · 已用时 m:ss」+ 不确定进度条 |
| 待完成 | 空心圆环 + 「等待中」 |
| 完成 | 绿点 + 「已完成」 |
| 失败 | 红点 + 红字步骤名 + 一行原因（如「pip 安装超时（镜像不可达）」） |

**关键约束（不拦路）**：环境未就绪时「开始浏览」**始终可用** —— 浏览、搜索、看代码不依赖运行环境，
只有「运行」需要。页脚明说这一点，避免用户以为要干等。

**失败态出口**（板 3）：`重试`（accent）/ `查看准备日志`（ghost）/ `用系统 Python 继续`（文字按钮）。
页脚说明「浏览不受影响；未装依赖的示例运行时提示缺依赖」。

**跳过与再触发**：「跳过引导」写入标记直接进主界面，环境继续后台准备；若准备失败，主界面状态栏
显示可点开的失败入口（该入口属 A6 失败恢复，见 §5）。

## 4. 数据来源与待接线（**实现前必须补齐**）

| 需求 | 现状 | 待接线 |
|---|---|---|
| 应用版本 / Electron 版本 | 主进程已有（`app.getVersion()`、`process.versions.electron`，见 `M/index.ts:1459` 的 about 面板） | 新增 IPC 暴露给渲染层 |
| 共享环境路径 / Python 版本 / 就绪态 | sidecar 有（`.venv` 路径、`sys.version`），**只打进了日志** | 新增 RPC（如 `env_status`）或在 `status` 通知里带字段 |
| 准备步骤与耗时、失败原因 | `_warmup_venv` 只在日志打点（`[系统] 虚拟环境准备失败，回退系统 Python`） | sidecar 上报阶段事件：`{step, state, startedAt, error}` |
| 「查看准备日志」 | 无 | 新增 IPC：`shell.openPath(日志文件)` |
| 已看过引导 | 无 | 复用现有 `store:set('onboarding', …)`（无需新接口） |
| 示例库规模 / 用户集合数 | 渲染层 store 已有 | 直接消费 |

> 上述 RPC/IPC 属 **B2（sidecar 重写）/ B3（渲染层与壳）** 的范围；本稿只锁定**字段与状态口径**，
> 实现时按 B 轨的协议设计落地，避免 A 轨自行发明通信方式。

## 5. 与 A6 的边界

本批只到「**准备过程可见 + 失败可重试**」。以下归 A6（产品化补课·失败恢复）：

- 状态栏的常驻环境入口（就绪/准备中/失败的持续可见与再进入）
- 依赖安装失败的**部分成功**处理（哪些包失败、是否可只重装缺失项）
- 运行期错误与「缺依赖」的一键修复闭环

## 7. 决策记录（已拍板 2026-09-29）

1. **失败态用显式三出口**：`重试` / `查看准备日志` / `用系统 Python 继续`。
   把现状"运行失败时自动回退"的隐式行为提为**知情选择**，对齐验收标准「失败必可见可操作」。
   **落地代价**：sidecar 需支持「本次用系统解释器」模式（归 B2 协议设计）。
2. **侧栏入口文案 = 「帮助」**，hover 提示「帮助与快捷键（⌘/）」；面板标题仍为「帮助与快捷键」。
   侧栏不加长、条目数不变。
3. **保留三步用法卡片**：首启页同时回答「能干什么」与「环境好了没」；准备期间有内容可读。
