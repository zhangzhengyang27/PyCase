# 非工具示例交互化调研（2026-10-03）

> 范围：1464 条总库中 1327 条非工具示例（工具 137 条已在 W1-W15 全部页面化）。
> 问题：这些示例中哪些可以改造为可交互的页面工具？

## 1. 结论一览

1327 个非工具示例按交互潜力分五层：

| 层 | 数量 | 交互化方向 | 归并后页面数 | 可行性 |
|---|---|---|---|---|
| **图表生成器** | 449 | matplotlib 参数化绘图 → PNG 预览 | ~35 | ★★★ 最高 |
| **图像效果实验室** | 313 | PIL/OpenCV 效果 → PNG 预览 | ~25 | ★★★ |
| **算法可视化** | ~63 | 参数调优 + 过程展示 | ~15 | ★★ |
| **实用爬虫工具** | ~5 | HTTP 请求器/解析器 | ~5 | ★★ |
| **保持原样** | ~797 | turtle/pygame GUI 循环、教学爬虫、一次性脚本、纯教学演示 | 0 | — |

**归并原则**：97 种图表去重同类型后 ~35 种核心（"折线图/多系列折线/双轴折线"合为一个交互页）；
40 种图像效果去重 PIL/OpenCV 同效果后 ~25 种；参数空间（数据分布/颜色/尺寸/阈值）在页面内调节，
覆盖该类型的全部存量变体——**一个页面替代一类变体**。

### 2.5 保持原样（~797 个）

- **turtle 345 + pygame 13 + 其他 GUI 25 = 383**：GUI 循环程序，页面化=启动器，丧失教学意义。
  turtle 图案（螺旋/分形/玫瑰线）可用 PIL 等效产出 PNG，但那是在教 PIL 而不是 turtle——
  保持 turtle 示例原样才是对的。
- **爬虫教学 58**：概念讲解型（重试退避/Cookie 会话/限速/robots.txt），工具化丧失教学结构。
- **showcase 基础教学 21**：你好世界/推导式/装饰器/生成器 → 手册页模式已覆盖。
- **migrated 一次性 57**：课程脚本无复用面。
- **bulk_basics 纯教学残余 ~46**：已被 W1-W3 或上述归并覆盖。

加上已有 128 个工具页面 → 总计 ~208 个交互页面覆盖 1464 条全库的 ~85%。

## 4. 关键前提

- **框架已就绪**：schema 驱动 + file 管道 + runImages 预览 + adhoc 运行——图表/图像工具
  只需注册 schema（fields + pyCode），零框架改动。
- **唯一缺口**：图表生成器的 pyCode 需要 matplotlib 脚本模板（每种图族一个）+ 数据参数化
  （CSV 粘贴 or 内置分布）。数据输入建议用 CSV textarea（复用 ToolField 现有能力）。
- **变体退役**：图表/图像类退役后，turtle(345)/pygame(13) 仍保留在库中（教学不可替代），
  总库缩减 ~590 条（1464→~874），画廊体量大幅精简。
