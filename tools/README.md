# 实用工具集

本目录包含 7 个独立运行的 Python 实用工具，覆盖数据库、Excel、网络、GUI 等场景。

## 工具列表

| 工具 | 说明 | 主要依赖 |
| --- | --- | --- |
| [db-table-dictionary-generator](./db-table-dictionary-generator/) | 自动生成 MySQL 表结构数据字典（Markdown 格式） | pymysql |
| [excel-row-to-in-clause](./excel-row-to-in-clause/) | 读取 Excel 指定列数据，拼接为 SQL IN 子句 | pandas |
| [python-black-magic](./python-black-magic/) | 远程 Wake-on-LAN 唤醒电脑 | socket |
| [remote-sftp-downloader](./remote-sftp-downloader/) | 通过 SFTP 从远程服务器批量下载文件/文件夹 | paramiko |
| [tkinter-work-countdown](./tkinter-work-countdown/) | Tkinter 下班倒计时桌面应用 | tkinter |
| [utility-crawlers](./utility-crawlers/) | 爬虫合集：糗百、妹子图、拉勾、豆瓣、必应、知乎等 | requests、BeautifulSoup |
| [wechat-official-account](./wechat-official-account/) | 微信公众号开发：消息收发 + 人脸检测 | falcon、wechatpy、opencv-python |

## 说明

每个工具为独立项目，进入对应目录查看详细说明和运行方式。
