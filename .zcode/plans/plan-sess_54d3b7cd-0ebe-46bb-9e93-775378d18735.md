# 实施计划：画廊/工具箱页面重设计——从「平铺清单」到「结构化浏览」— v0.10.0

## 诊断（页面级，非卡片级）

截图实证：打开画廊 = 整个视口被两种文字墙填满。
- **右栏**：1187 个示例无差别平铺（4 列同构卡、12px 间距、触底无限加载），库的结构（5 大主题 1161 个 / 工具 34 个 / 项目 51 个）在页面上完全不可见——全部被压平成「第 1~120 个」，没有分区、层级、节奏，滚动是唯一导航。
- **左栏**：36 行筛选全部常驻（含每行 mono 计数），与右栏拼成一屏小号文字，无一处视觉休息区。
- **工具箱**：34 个条目套用大卡片墙，形态与数量错配。
- 根源是**信息架构**：库有天然组织（主题谓词 turtle/games/opencv/images/viz 已存在且各有计数），但页面不表达结构，主题只是侧栏筛选行。

**明确不做**：ExampleCard 卡片内部结构不动（用户已确认不是卡片密度问题）；不引第三方虚拟滚动库。

## 设计

### 1. 画廊两级浏览（核心改动）

**总览态（新默认落地页，隐藏侧栏、全宽）**：

```
┌──────────────────────────────────────────────────────────────┐
│ 示例库                                                        │
│ 1187 个示例 · 5 大主题 · 87% 可静态运行     [浏览全部] [我的收藏] │
├──────────────────────────────────────────────────────────────┤
│ 🐢 Turtle 绘图                                    233 个 →    │
│ ┌──────┐┌──────┐┌──────┐┌──────┐┌──────┐┌──────┐  ←横向带(可轻滚)│
│ │ card ││ card ││ card ││ card ││ card ││+229→ │             │
│ └──────┘└──────┘└──────┘└──────┘└──────┘└──────┘             │
│                                                              │
│ 🕹️ Pygame 游戏                                    194 个 →    │
│ ……（5 主题分区 + 其他示例区）                                   │
└──────────────────────────────────────────────────────────────┘
```

- 头区统计：examples.length、THEMES.length、可运行占比（`facetCounts.runnableCounts.get('runnable')`）。
- 每主题一个分区带：区头（emoji + 名称 + 计数 + 查看全部→）+ 前 8 张卡横向带（`flex gap-3 overflow-x-auto`，卡 `w-[220px] shrink-0`）+ 末尾「还有 N 个 →」more 卡（虚线边框）。
- 分区预览卡**互斥分配**（THEMES 顺序 first-match，一张卡只出现一次）；区头计数沿用现有 `themeCounts`（与侧栏同源同数）。剩余未匹配者归「其他示例」区。
- 「查看全部」/ more 卡 / 头区入口 → 进入浏览态并应用对应筛选。

**浏览态（下钻后，现有网格增强）**：

```
┌──────────┬───────────────────────────────────────────────────┐
│ 筛选侧栏  │ ← 总览 │ 🐢 Turtle 绘图   [筛选芯片…×]  [排序▾] [⊞|☰] │
│ （折叠分组）├───────────────────────────────────────────────────┤
│          │  网格（呼吸感加强）或 列表（新增）                       │
└──────────┴───────────────────────────────────────────────────┘
```

- 进入途径：点分区「查看全部」（设 activeTheme）/ 头区「浏览全部」（theme=all）/「我的收藏」（favOnly）；侧栏点击任何筛选自然处于浏览态。
- 结果条（新 BrowseToolbar，画廊浏览态与工具箱共用）：左「← 总览」（仅画廊）+ 当前范围标题；中筛选芯片（可逐个移除 + 「清空」）；右排序 + 网格/列表切换。
- 筛选芯片：新纯函数 `filter-chips.ts`，从当前 query 生成 {key, value, label}[]，覆盖 fav/运行状态/可运行性/主题/质量分/标签/搜索词。
- 网格呼吸感：`minmax(260px)→272px`、`gap-3→gap-4`、`p-3→p-4`。
- **列表视图（新增密度切换，viewMode 'grid'|'list' 持久化进 viewPrefs）**：h-11 一行一例（小色块图标 + 名称 + 一行描述 + 负面/高危徽章 + 低分质量 + hover 浮现收藏/运行），共用新组件 ExampleListItem；列表态 PAGE_SIZE=160。

### 2. 工具箱清单化

- 34 个工具改**列表为默认形态**（ExampleListItem），保留网格切换；补齐排序下拉（复用 sortExamples）。
- 不做分区总览（数量小，无需两级）。

### 3. 侧栏降噪（浏览态内）

- 五个组（运行状态/可运行性/主题/质量分/标签）改为可折叠分组：组头 = chevron + 组名 + 激活数徽标；默认「主题、质量分」收起，其余展开；标签 TopN 15→10。
- 行样式与计数保持不变。

## 工作项

**A. 数据与纯函数（store + src/）**
- 新建 `src/renderer/src/overview.ts`：`assignSections(examples) -> {key, items}[]`（THEMES first-match 互斥 + others 桶，纯函数）。
- 新建 `src/renderer/src/filter-chips.ts`：`buildFilterChips(query) -> Chip[]`（纯函数）。
- `store.ts`：`galleryMode` ref（'overview'|'browse'，不持久化）+ `openGalleryBrowse()` 助手；`viewMode` ref + applyViewPrefs/persistViewPrefs 扩展；`chipsFor(scope)` computed + `removeChip(scope, chip)`；工具箱排序接入（toolboxItems 走 sortBy）。
- node 测试：`tests/test_overview.mjs`、`tests/test_filter_chips.mjs`。

**B. 画廊双态（GalleryView 重构）**
- 新建 `components/GalleryOverview.vue`：头区 + 分区带（横向滚动 + more 卡）。
- 新建 `components/BrowseToolbar.vue`、`components/ExampleListItem.vue`。
- `GalleryView.vue` 改为双态容器：overview（全宽）v-show / browse（现有侧栏+结果条+网格，换 BrowseToolbar，加列表态与分页复用）；空态/加载/错误分支两态各自处理。

**C. 工具箱 + 侧栏**
- `ToolboxView.vue`：换 BrowseToolbar（无返回钮）+ 列表默认 + 排序。
- `FilterSidebar.vue`：分组折叠（本地 ref，不持久化）+ 标签 TopN 10。

**D. 冒烟与发版**
- `npm run smoke` 回归（探针纯 store API，预期零改动；如有断言差异修正探针）。
- README 特性句 + ROADMAP Done（v0.10.0）；升版 0.10.0 + tag。

## 提交切分
1. `feat(ui): 画廊总览态——主题分区落地页 + 下钻浏览`（A 的 overview 部分 + B）
