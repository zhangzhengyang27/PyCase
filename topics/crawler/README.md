# Web Crawling

本目录包含 **Web Crawling**（网络爬虫：Requests、BeautifulSoup、Scrapy、JS 逆向）相关的学习代码与资料。

## 子目录

| 主题 | 目录 |
| --- | --- |
| B站数据抓取工具集 | `bilibili/`（独立可运行，见其 README） |
| BeautifulSoup 解析 | `beautifulsoup/` |
| 并发爬虫 | `concurrent-crawling/` |
| HTTP 请求基础 | `http-requests-basics/` |
| JavaScript 逆向 | `js-reverse/` |
| Python 工程师爬虫实战 | `python-engineer-spider/` |
| Requests 进阶 | `requests-advanced/` |
| Requests + BeautifulSoup | `requests-beautifulsoup/` |
| Scrapy 项目实战 | `scrapy-projects/` |
| Selenium 进阶 | `selenium-advanced/` |

## 说明

- 子目录按主题或来源组织。
- 运行代码前请确保已激活根目录虚拟环境：`source .venv/bin/activate`。
- 依赖见根目录 `requirements.txt`。
